# TadClip (ตัดต่อคลิป)

ตัดต่อคลิปพูดหน้ากล้องให้เป็นรีลแนวตั้งด้วย AI บนคอมของคุณเอง เลือกเทคที่ดีที่สุด ตัดช่วงเงียบ ซับไทย ตัวหนังสือเคลื่อนไหว
เสียงประกอบ เพลง ภาพประกอบ และแบรนด์ของคุณ

**ใช้ได้เมื่อมีรหัส TadClip** ซื้อได้กับคลาส TadClip × ClubGig (สอบถามทาง LINE ของ ClubGig) ได้รหัสทาง LINE หลังชำระเงิน

## ติดตั้ง (มีรหัสแล้ว)
**Mac** (ชิป Apple M1 ขึ้นไป macOS 14 ขึ้นไป): เปิด Terminal แล้ววาง
```
curl -fsSL https://raw.githubusercontent.com/npnatt12/tadclip-assets/main/install.sh | bash
```
**Windows 10/11 แบบ 64 บิต** (ทดลอง): เปิด PowerShell แล้ววาง
```
irm https://raw.githubusercontent.com/npnatt12/tadclip-assets/main/install.ps1 | iex
```
เมื่อขึ้นว่า "วางรหัส TadClip" ให้วางรหัสที่ได้ทาง LINE แล้วกด Enter · ต้องมี Claude แบบ Pro (สมัครเองที่ claude.ai)

## ในนี้มีอะไร

- `release.json`: ข้อมูลรุ่นล่าสุด (ไม่มีความลับ)
- Releases `music-v1`: เพลงประกอบ 23 เพลง โดย Kevin MacLeod ผ่าน FreePD เป็น CC0 (สาธารณสมบัติ) ดู CREDITS.txt
